# P0/P1 해안 차분 진단과 보정 제안

**최신 상태:** 이후 사용자 명시 승인으로 해양 이웃 차분 660개 방식과 30회 실행이 확정됐다. 아래 선택대기 문장은 검토 당시 이력이다. GPU 사전 검증 뒤 실행한다.

2026-09-25. 30회 파일럿의 본 학습 전에 발견한 수치 경계 처리 문제다. 기존 모델, 분할, 통계 파일, 학습 결과는 변경하지 않았다. 30회 범위는 승인됐지만 아래의 해안 처리 변경은 사용자와 선택 중이며 본 학습은 시작하지 않았다.

## 발견된 문제

원래 데이터로더는 SST의 육지 NaN을 0으로 채운다. `spatial_gradients_torch`는 중앙차분 시 이 육지 값을 사용하고, 물리 손실에서 바다 격자만 선택한다. 차분 뒤의 마스킹은 이웃 바다 격자에 이미 들어간 육지 0°C의 영향을 제거하지 못한다. 따라서 경계의 인공적 기울기는 수치 구현상 결함이다. P0 열수지 식 전체가 잘못됐다는 결론은 아니다.

29×33 격자의 바다 661개 중 141개가 육지와 맞닿은 차분을 사용한다. 실제 원자료의 육지 SST는 NaN이며, 기존 nan_to_num 뒤에는 0이다. 관측 해양 SST를 사용한 학습 구간 진단에서 다음을 얻었다. 512개 창은 원래 학습 인덱스에 균등하게 배치했고, 검증·테스트 자료는 쓰지 않았다. 아래 진단은 we=0으로 분해한 값이다.

| 항목 | 내부 바다 520개 | 육지에 닿는 차분 141개 |
|---|---:|---:|
| 관측 일별 온도 경향 RMS (K/day) | 0.3713 | 0.3710 |
| 이류항 RMS (K/day) | 0.1816 | 6.7494 |
| P0 물리 잔차 RMS (K/day) | 0.4181 | 6.7544 |

관측 일별 경로와 관측 끝점의 선형 경로 모두 큰 경계 오차를 보였다. 따라서 선형 시간 경로만을 원인으로 지목하면 안 된다. 실제 원자료의 육지 값도 0으로 처리되므로, 끝점을 ocean-node 그리드로 변환하는 과정만의 문제도 아니다.

## 두 대안

1. 완전한 바다 중앙차분만 물리 손실에 사용: 520/661개 유지. 구현과 해석이 단순하지만 21.3%의 해양 격자가 물리 제약을 받지 않으므로 해안 성능에 대한 근거가 제한된다. 유용한 민감도 비교 후보이며 이 방법 자체가 부당한 것은 아니다.
2. **권고: 해양 이웃 차분**. 축별로 양쪽 이웃이 바다면 기존 중앙차분, 한쪽만 바다면 바다 방향의 한쪽 차분을 사용한다. x/y 방향 모두 해양 이웃을 갖는 660/661개에서 물리 손실을 적용할 수 있다. 남북 이웃이 없는 위치 [24,14] 한 개만 물리 손실에서 제외한다. 온도 학습과 평가는 661개 전체에서 유지한다.

중앙/한쪽 차분은 일반적인 수치 미분 방식이다([NumPy 공식 설명](https://numpy.org/doc/2.0/reference/generated/numpy.gradient.html)). 이 근거가 해양 경계에서의 정확성을 모두 보장하지는 않는다. 한쪽 차분은 1차 근사이고, 이 대안이 보존형 해양 수치모형이나 완전한 해안 경계조건을 구현하는 것은 아니다. 육지 채움값을 실제 온도로 사용하는 문제를 제거하는 최소한의 경계 미분 보정으로 설명한다.

## 검증된 사실과 남은 실행

- `check_ocean_neighbor_gradients.py`: 선형 온도장 미분 정확성, 육지 채움값 0/-100/1000에 대한 불변성, 육지로 흐르는 gradient가 0임, 해양 이웃 없는 격자 제외, autograd와 유한차분 일치를 통과했다.
- `check_physics_interval.py`: 일정/교대 forcing의 해석적 손실, P1 수직항 부호와 단위, 예측과 무관한 forcing의 경우 일별/기간평균 gradient가 같을 수 있음, 이류가 예측에 의존할 때 gradient가 달라짐, 유한차분 검증을 통과했다.
- Full train 7,644개를 사용한 기존 P0 RHS 제곱평균 재계산은 9.7367229942이며 기존 저장값 9.7367229778과 일치했다. 해양 이웃 차분·유효 660개로 계산하면 0.08996321398 (K/day)²다. 새 값은 별도 JSON에 저장했고 기존 통계를 덮어쓰지 않았다.
- 승인 후 P0/P1·일별/기간평균 모두 동일한 보정 방식과 동일한 새 Full-train P0 RHS 스케일을 사용해야 한다. 입력/타깃 정규화는 기존 Full 통계를 그대로 유지한다. 같은 숫자의 lambda가 기존 실험과 같은 유효 제약을 뜻하지 않으므로 새 lambda 스윕이 필요하다.
- 물리 손실의 차분 보정은 기존 RMSE 측정값을 무효로 만들지 않는다. 그러나 기존 결과를 정상적인 열수지 제약의 효과로 해석하는 데 제한을 준다. 새 실험과 기존 실험은 보조손실·경계 처리·RHS 스케일이 함께 달라지므로 그 사이 성능 차이를 경계 보정 하나의 인과 효과로 주장하지 않는다.
- 새 학습 실행기와 자동 요약은 준비 중이다. 본 GPU smoke 및 30회 본 학습은 아직 실행하지 않았다. 원본 src는 보존한다.

## 승인된 실행 범위와 선택 대기 사항

10% subset376개, lead7, seed42/7/123. 맞춘 baseline 3회 + 순수 P0 일별 9회 + 순수 P0 기간평균 9회 + 순수 P1 일별 9회 = 30회. 세 물리 조건의 lambda는 0.01/0.1/0.3, 보조손실 가중치는 0. baseline의 물리 가중치는 0이다. 초기화와 배치 순서, 모델, 시간 분할, 온도 평가 영역은 일치시킨다. lambda 선택은 세 seed 평균 검증 RMSE이며 공통 lambda0 baseline도 후보에 포함한다. 기존 테스트를 보고 발전시킨 탐색적 연구임을 유지한다.
